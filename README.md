# InclusaVision
Inclusa Vision: Mobilidade urbana acessível com assistente de voz, layout adaptativo e painel de preferências para PCDs. Desenvolvido em React e Tailwind para garantir autonomia e segurança no transporte público com tecnologia inclusiva. 

# Inclusa Vision (InclusaV)

O **Inclusa Vision** é uma plataforma progressiva de mobilidade urbana focada em acessibilidade, projetada para auxiliar usuários com diferentes necessidades (especialmente deficiências visuais e auditivas) a navegar pelo sistema de transporte público com autonomia e segurança.

## Funcionalidades

- **Interface Adaptativa:** Layout limpo e de alto contraste, otimizado para facilitar a navegação sem rolagem excessiva.
- **Assistente de Voz Integrado:** Feedback por voz automático para navegação e suporte a comandos de voz.
- **Painel de Acessibilidade:** Opções personalizáveis para feedback tátil, fontes grandes e modos de visualização (Claro/Escuro).
- **Busca de Ônibus:** Interface simplificada para consulta de horários e itinerários com visualização de mapa integrada.
- **Sistema de Favoritos:** Acesso rápido às rotas e destinos mais frequentes do usuário.
- **Central de Ajuda:** Chat de suporte e FAQ focado nas dúvidas mais comuns de acessibilidade.

##  Tecnologias Utilizadas

- **React 18** & **TypeScript**
- **Vite** (Ambiente de desenvolvimento ultra-rápido)
- **Tailwind CSS** (Styling responsivo e moderno)
- **Lucide React** (Biblioteca de ícones acessíveis)
- **Framer Motion** (Para transições de tela e animações fluidas)
- **Web Speech API** (Utilizada para as funcionalidades de voz e leitura de tela)

##  Como rodar localmente (VS Code)

1. **Extraia os arquivos** ou faça o download do ZIP do projeto.
2. No **VS Code**, abra a pasta raiz do projeto.
3. Abra o terminal e instale as dependências e inicie o servidor:
   ```bash
   cd inclusav
   npm install
   npm run dev     # http://localhost:3000
   npm run build   # produção
   ```
5. Acesse no seu navegador através do endereço `http://localhost:3000`.
